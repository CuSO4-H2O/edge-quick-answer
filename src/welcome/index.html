划词答题助手 已就绪

装好了。这里花一分钟说明它需要什么权限、以及为什么。

为什么它要"读取你访问的所有网站"？

因为这类工具必须在网页上运行才能工作：划词浮标、读取题干和选项、 框选截图，都发生在你正在看的那个页面上。扩展本身无法预知你会打开哪个题库， 所以只能声明"所有网站"。

顺带说明：本扩展的划词脚本本来就在所有网页上运行 （这是内容脚本的固有机制）。这次新增的权限只是让后台能够调用截图接口， 同时把这项能力在权限列表里显式写出来 —— 而不是悄悄获得。

它实际会做什么 / 不会做什么

  • 会：只在你划词或点按钮时，读取当前页面的文字
  • 会：把选中的文字、题干，以及你框选的截图， 发给你自己配置的 DeepSeek API 做解答
  • 不会：收集浏览记录、上传你访问的网址
  • 不会：把数据发给开发者或任何第三方
  • 不会：在后台自动运行或自动提交答案

API Key 只保存在本机（扩展存储），除了直接发给 api.deepseek.com 之外不会离开你的电脑。

怎么用

  1. 点浏览器工具栏上的扩展图标，在 ⚙ 设置里填入 DeepSeek API Key
  2. 在网页上选中题目文字 → 点浮出的「做题」
  3. 浮层里会直接给出答案和理由；可以接着追问

截图提问：点浮层顶栏的 ⛶，或右键菜单「截取区域问 AI」， 然后框选区域即可。也可以按 Alt+Shift+S 直接针对整页提问。

如果扩展被自动停用了

新增权限后，浏览器出于安全考虑会暂时停用扩展，直到你确认。 遇到这种情况，去 edge://extensions 把它的开关重新打开即可 —— 这是浏览器的设计，不是出错了。
